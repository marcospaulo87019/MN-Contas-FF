# MN Contas FF — site inicial

Site estático em HTML e CSS, preparado para publicação no GitHub Pages.

## Antes de publicar
1. Edite os anúncios de exemplo no `index.html` e substitua nome, descrição, preço e imagens por informações reais.
2. Configure o link do WhatsApp. Procure `https://wa.me/5500000000000` e troque pelo número comercial com código do país e DDD, somente números.
3. Não anuncie como "100% seguro" sem conseguir garantir isso; explique com precisão as condições, entrega e suporte.
4. Verifique os termos aplicáveis do Free Fire sobre transferência e venda de contas.

## Publicar no GitHub Pages
1. Crie um repositório público chamado `MN-Contas-FF`.
2. Envie o arquivo `index.html` para a raiz do repositório (e este README, se quiser).
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/(root)`, depois clique em **Save**.
6. Aguarde a publicação. O GitHub mostrará o endereço do site na própria seção Pages.

Este site é apenas a vitrine. Ele não processa pagamentos nem confirma estoque automaticamente.
